관찰된 트렌드

  • ERP 교체가 아닌 AI 보완: 케어플래너·CleanCheck는 기존 ERP 옆에서 서류·점검·기록을 줄이는 포지션이다.
  • 공단 연동+급여 자동화: 재가 중심 제품은 일정·청구·급여·본인부담금 흐름을 핵심 가치로 제시한다.
  • 보호자 채널 확장: EcM 홈페이지, 케어포 가족앱, 웰파트너스 가족 케어앱처럼 B2B 운영을 넘어 보호자 경험을 포함한다.
  • 감사·리스크 자동화: 평가 서류, RFID 검수, CCTV 비식별화, 사전 경보가 차별점으로 부상한다.

다음 조사 우선순위

  1. 각 제품의 실제 유료 기관 수·월 사용료·해지 조건을 영업 문의로 검증
  2. 공단 연동 범위, 개인정보 처리·AI 학습 경계, 로그 보존을 데모에서 확인
  3. 직영 장기요양기관 운영 여부와 현장 데이터 접근성을 법인 단위로 검증
  4. 동일 기관 시나리오(방문요양 50명/요양원 49인)로 도입·교육·이관 비용 비교
