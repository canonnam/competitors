경쟁사 UIUX 분석

엔젤시스템·케어포·더비다의 장기요양 ERP 화면을 나란히 놓고, 누가·언제·얼마나 빨리·실수 없이 일을 끝내는지를 기준으로 비교합니다. 더비다는 자사 제품이지만 점수를 부풀리지 않았습니다. 2026-09-18 실입력 사용성 테스트([UXTEST-20260918])를 함께 수록합니다. 기능·가격 비교는 경쟁사 분석에서 확인합니다.

대상: 엔젤시스템 · 케어포 · 더비다자료 기준 2026. 09. 18캡처 정성 분석 · 실입력 사용성 테스트 [UXTEST-20260918]

카드·모달·위자드·뱃지로 인지 부하를 낮춥니다. 신규·비전공 담당자에게 유리합니다.
경쟁사가 아직 편한 축
일괄 · 서식 · 숙련 속도
엔젤은 표·메뉴 밀도, 케어포는 평가↔계획 근거·캘린더·마스터디테일 HR이 강합니다.
회의에서 잡을 메시지
예쁜가가 아니라 업무가 짧은가
임상·일상 UX는 더비다 우위. 원무·문자·프로그램·점검·HR·설정은 아직 경쟁사 패턴을 흡수해야 합니다.

총평. 임상·일상 화면(등록·평가·투약·계획·건강)에서는 더비다의 가독성과 학습 비용이 대체로 앞섭니다. 본인부담·문자·프로그램 일정·사례회의 규제 대응·정기점검 연간보드·직원 HR 깊이·시설 설정에서는 엔젤·케어포가 숙련 속도와 한눈에 보기에서 아직 더 편합니다. 더비다는 뼈대(캘린더·뱃지·탭)는 맞지만, 채워진 운영 밀도와 규제 대시보드가 비어 보이는 화면이 있습니다.

한눈에 보기 화면별 편의 입소자 등록 기초평가 욕창 Braden 투약 급여계획 요양기록 외출외박 건강기록 본인부담금 메시지 프로그램 회의·교육 정기점검 직원관리 설정 사용성 테스트 개선 로드맵

AT A GLANCE

화면별 편의성 한줄

경영진이 바로 읽을 수 있게, 누가 쓰기에 더 편한지만 적었습니다. 더비다 편향 없이 적었습니다.

화면가장 편리한 쪽한줄 이유
입소자 등록더비다세로 플로우·여백으로 신규 담당 실수가 적음. 행정 필드는 단계로 보완.
기초평가 목록더비다“이 사람 지금 위험한가” 스캔이 카드+뱃지로 가장 빠름. 일괄은 엔젤.
욕창(Braden) 입력더비다세로 라디오+실시간 위험 요약. 숙련 비교용 매트릭스는 옵션이면 충분.
투약 등록더비다 (근소)검색·가독성 우위. 다건 속도는 엔젤, 스케줄 구조는 케어포.
급여제공계획작성: 더비다 / 근거: 케어포위자드+AI는 작성 부담↓. 기초평가 요약 패널은 케어포가 강함.
요양기록지당일: 엔젤 / 주간: 케어포·더비다현장 속도는 엔젤형. 더비다는 오늘 모드가 필요.
외출·외박운영: 더비다 / 증빙: 엔젤시설 현황판은 더비다, 서명·면회 대장은 엔젤. 개인이력은 케어포.
건강기록더비다 (구조)일일 저널 + 임상 허브 분리는 맞음. 이중 입력만 막으면 경쟁 우위.
본인부담금청구·발송: 엔젤 / 현황 스캔: 더비다대장+알림톡 일괄은 엔젤, 합계·결제·발송 뱃지 읽기는 더비다.
메시지 전송SMS: 케어포 / 가정통신문: 더비다보호자 선택→확인→작성 3열이 문자 업무에 가장 직관. 더비다 SMS 콘솔은 약함.
프로그램 기록케어포월간 캘린더에 색·시간·참여자없음·작성하기가 이미 채워져 있음.
회의 및 교육케어포분기 실시현황 + 회의록 + 급여반영이 한 화면에 묶여 규제 대응이 짧음.
정기점검월별: 케어포 / 연간총괄: 엔젤소방·전기·가스 월칸은 케어포, 기관운영 전체 점검은 엔젤. 더비다는 로그형.
직원관리케어포목록+상세+자격·4대보험·연차까지 마스터디테일이 실무 HR에 가장 가깝다.
설정시설환경: 케어포 / 기관정보: 엔젤시설·서비스 토글 감사는 케어포, 기관 식별·직인·결재는 엔젤. 더비다 캡처는 계정설정만.

01 · 임상

입소자 / 수급자 등록 편의성: 더비다

온보딩은 더비다가 편하고, 숙련자의 한 화면 일괄 입력은 엔젤이 빠릅니다.

엔젤

  • 장점 등급·본인부담·보호자까지 한 화면, 숙련자 속도가 높음
  • 단점 초고밀도, 학습 곡선과 실수 위험이 큼
정보 밀도 최상 · 학습 곡선도 최상

케어포

  • 장점 모달로 신규등록 태스크 경계가 명확
  • 단점 모달 안 2열 그리드는 여전히 빡빡
태스크 포커스 좋음 · 폼은 관리형

더비다

  • 장점 섹션 분리·큰 입력·등록 CTA가 명확, 현장 가독성↑
  • 단점 한 화면 행정 필드가 적어 숙련자에게는 단계가 늘어난 느낌
온보딩·실수 감소 강함 · 파워유저 속도 보완 여지
더 편한 쪽

신규 담당 기준으로는 더비다가 더 편리합니다. 등급·본인부담 같은 행정 블록은 2단계나 접기로 엔젤 밀도를 필요할 때만 흡수하는 편이 낫습니다.

인사이트. 한 화면에 다 넣기는 숙련자 최적화입니다. 이직이 잦은 현장에서는 비숙련 기준이 병목이 됩니다.

02 · 임상

기초평가 목록 편의성: 더비다

낙상·욕창·인지·욕구사정. 판단 스캔은 더비다, 유형별 일괄은 엔젤이 편합니다.

엔젤

  • 장점 평가유형별 일괄·필터·엑셀에 강함
  • 단점 같은 입소자 종합 위험이 메뉴를 넘나들며 끊김
서식/평가도구 중심 · 사람 중심 약함

케어포

  • 장점 한 탭에 4종 요약 표, 이력 비교 가능
  • 단점 셀이 작아 가독성·행동 유도는 중간
통합은 잘함 · 읽기는 보통

더비다

  • 장점 카드+위험 뱃지로 “지금 상태” 스캔이 가장 빠름
  • 단점 시계열 이력·유형별 일괄은 보강 필요
판단용 UI 최고 · 이력/일괄은 숙제
더 편한 쪽

라운딩·인수인계에는 더비다가 가장 편리하고, “오늘 욕창만 일괄” 같은 배치 작업은 엔젤식 메뉴/필터가 편합니다.

인사이트. 엔젤의 메뉴 분리는 서식=메뉴이고, 더비다·케어포는 사람=허브입니다. 현장 질문은 대부분 사람에서 시작합니다.

03 · 임상

욕창위험도(Braden) 입력 편의성: 더비다

엔젤·케어포는 6×4 매트릭스, 더비다는 세로 라디오 + 우측 실시간 요약입니다.

엔젤

  • 장점 1~4점 문구 가로 비교, 서식 충실
  • 단점 글자가 작고 합산·위험도가 묻힘
서식 충실도↑ · 입력 중 인지부하↑

케어포

  • 장점 입소자 맥락·총점 강조가 엔젤보다 낫다
  • 단점 입력 골격은 같은 매트릭스
맥락·마무리는 개선 · UX 골격은 동급

더비다

  • 장점 항목별 선택 + 실시간 총점/위험 피드백
  • 단점 가로 비교↓, 미완료인데 고위험처럼 보일 위험
입력·피드백 UX 강함 · 완료 상태 표현만 다듬기
더 편한 쪽

더비다가 분명히 더 편리합니다. 태블릿·초보 간호사 기준으로 실수와 피로가 가장 적습니다. 숙련자용 “표로 보기” 토글만 있으면 매트릭스 세대도 수용할 수 있습니다.

인사이트. 평가 입력에서 중요한 것은 점수 자체가 아니라 위험 인식의 즉시성입니다.

04 · 임상

투약 등록 검색: 더비다 · 다건: 엔젤 · 스케줄: 케어포

실수 비용이 큰 도메인입니다. 단일 약 검색은 더비다, 연속 등록 속도는 엔젤, 복약 시점 구조는 케어포가 편합니다.

엔젤

  • 장점 그리드 인라인으로 다건 연속 등록 속도↑
  • 단점 작은 필드, 검증이 행에 묻혀 오입력 위험
배치 입력형 파워툴 · 안전·가독성 희생

케어포

  • 장점 모달 + 매일/주기/PRN 스케줄 구조화
  • 단점 체크·작은 칸이 많아 밀도 잔재
태스크 분리는 정답 · 폼 밀도는 과제

더비다

  • 장점 공공/원내 검색 탭, 큰 폼, 효능·비고
  • 단점 시점 시인성·용량 검증·다건 속도
검색·가독성 최강 · 스케줄/검증 보강 여지
더 편한 쪽

단일 약 등록·검색은 더비다가 더 편리합니다. 약을 10개 연달아 넣는 숙련 작업은 아직 엔젤이 빠를 수 있습니다. 저장 후 ‘이어서 추가’와 복약 시점 칩·용량 자동검증이 있으면 안전과 속도를 같이 가져갑니다.

인사이트. 투약 UX의 승부처는 예쁜 모달이 아니라 검색 정확도 + 시점 시인성 + 저장 전 확인입니다.

05 · 임상

급여제공계획 작성: 더비다 · 근거연결: 케어포

공단·문서 성격이 강해 “한 장 서식 vs 단계 위자드” 비교입니다. 작성 자체는 더비다, 왜 이 서비스인지는 케어포가 편합니다.

엔젤

  • 장점 공단연계 서식 완결성, 빈도·시간·횟수 밀도
  • 단점 체크 피로, 평가 근거와 단절되기 쉬움
서식 완결성↑ · 작성 경험↓

케어포

  • 장점 기초평가 요약을 계획 화면에 참조 — 근거 연결이 가장 강함
  • 단점 탭이 많아 전체 완성도 조망이 어려움
근거 연결 최고 · 가독성 중간

더비다

  • 장점 3단계 위자드, 항목 리스트, AI 추천 텍스트
  • 단점 공단 밀도·평가 근거 패널·단계 유연성 보강 필요
작성 UX·AI 차별화 · 근거/밀도 숙제
더 편한 쪽

계획 작성 자체는 더비다 위자드가 훨씬 편합니다. “왜 이 서비스인가”를 보려면 케어포식 평가 요약이 필요합니다. 1단계에 기초평가 패널을 붙이면 설득력이 완성됩니다.

인사이트. AI 추천은 시간이 아니라 신뢰가 상품입니다. 추천 문단에 평가·욕구 근거 태그를 붙이면 차별화를 방어할 수 있습니다.

06 · 임상

요양기록지 입력 당일: 엔젤 · 주간: 케어포/더비다

하루에도 수십 번 만지는 화면입니다. 더비다는 주간 가독성은 좋지만 오늘 모드가 없습니다.

엔젤

  • 장점 오늘 한 사람 팝업, +/- 횟수, 관찰 체크
  • 단점 빽빽함, 주간 추세는 약함
당일·현장형 최강

케어포

  • 장점 주간 그리드로 빈칸·편중 점검·인쇄
  • 단점 셀이 작아 현장 터치 입력 부담
관리·감사형 최강

더비다

  • 장점 주간 뼈대 + 여백·섹션·임시저장
  • 단점 당일 속도·관찰 칩·미기록 신호 보강 필요
주간형 중 가독성 최고 · 오늘 모드 필요
더 편한 쪽

한 화면으로 우승자를 정하기 어렵고, 그게 포인트입니다. 교대 중 입력은 엔젤형 오늘 모드, 주간 마감·점검은 더비다/케어포형 그리드가 편합니다.

인사이트. 예쁜 주간표만 있으면 요양보호사 현장 불만이, 당일만 있으면 관리자 불만이 납니다. 모드 전환이 정답입니다.

07 · 임상

외출·외박 관리 운영: 더비다 · 증빙: 엔젤

안전·청구·면회가 겹칩니다. 현황판은 더비다, 서명·면회 대장은 엔젤, 개인 이력은 케어포가 편합니다.

엔젤

  • 장점 대장 필드·보호자 서명·면회까지 한 모듈
  • 단점 실시간 “지금 밖에 누구” 스캔이 약함
증빙·대장형 최강

케어포

  • 장점 입소자별 이력·인쇄에 강함
  • 단점 시설 전체 현황판이 약함
개인 이력형

더비다

  • 장점 전체 목록·색 뱃지·등록 CTA·청구 신호
  • 단점 서명·면회 깊이·진행중 필터는 모달/필터로 보강
운영 가시성 최강
더 편한 쪽

당직·프론트의 지금 현황은 더비다가 가장 편리하고, 원무·분쟁 대비 증빙은 엔젤이 편합니다. 이상형은 더비다 목록 + 엔젤급 등록 모달(서명 포함) + 케어포급 개인 타임라인입니다.

인사이트. 현황 / 이력 / 증빙을 한 화면에 강제하면 모두가 불편해집니다.

인사이트. 실패 패턴은 분리가 아니라 동기화 없는 분리입니다. 딥링크·미입력 뱃지·이상치 필터가 연결 장치입니다.

10 · 운영

본인부담금 청구·발송: 엔젤 · 현황 스캔: 더비다

케어포

더비다

  • 장점 합계열 하이라이트·알림톡/결제 뱃지·상세보기로 스캔이 쉬움
  • 단점 공단부담·감경 세분·법적서식·미수 누적이 얇음
보호자·시설장 현황판형 · 원무 대장 깊이 부족
더 편한 쪽

월 청구를 계산·발송까지 끝내야 하는 원무에는 엔젤(또는 케어포 그리드)이 더 편합니다. 누가 미납/미발송인지만 빠르게 볼 때는 더비다 뱃지형이 낫습니다. 이기려면 엔젤급 컬럼/법적서식을 상세 모달·접기로 흡수하고 목록은 가볍게 유지해야 합니다.

인사이트. 본인부담 UX는 계산(원무) vs 안내(보호자) 두 질문입니다. 후자만 있으면 “예쁜데 청구는 엑셀”로 남습니다.

문자 발송 태스크 UX 최상

더비다

  • 단점 일반 SMS·잔액·예약·주소록형 콘솔이 안 보임
콘텐츠형 보호자 커뮤니케이션 · SMS 운영은 빈칸

인사이트. “수신 보호자 없음” 경고는 정직한 UX입니다. 그 자리에서 연락처를 고치는 CTA가 없으면 정직함이 곧 업무 중단이 됩니다.

프로그램 기록 편의성: 케어포

엔젤

인사이트. 프로그램 UX의 승부처는 AI 버튼이 아니라 빈칸이 보이는가입니다.

회의 및 교육 편의성: 케어포

인사이트. 회의 화면은 문서 에디터가 아니라 의무 주기 대시보드입니다. “아직 안 한 분기”가 먼저 보여야 시설장이 씁니다.

  3. 필수값 표시 강화. 대상자 선택은 버튼·검색·선택 완료 상태를 보여주고, 미입력 시 저장 차단 이유를 필드 옆에 둡니다.

  6. 빈 결과 진단. “없음”만 쓰지 말고 날짜·상태·대상자·권한 중 어떤 조건 때문인지 안내합니다.
