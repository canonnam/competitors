## 수정 범위

- ON/OFF는 캠페인·광고그룹·키워드 각각의 명시적 `userLock`을 사용한다. 해당 값이 없는 이전 자료는 기존 `ELIGIBLE` 대체 기준을 유지한다.
- 실제 집행 가능 여부와 상위 순위 신호는 기존 `eligible` 조건을 유지해 예산 제한 상태를 집행 가능으로 표시하지 않는다. 수동 OFF 키워드는 제외한다.
- 광고 계정의 예산·입찰가·ON/OFF는 수정하지 않고 조회·저장·분류만 갱신한다. 당일 성과를 추정하거나 API 광고 순위를 실제 웹 검색 결과로 대체하지 않는다.
