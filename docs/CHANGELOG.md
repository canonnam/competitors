# 더비다 지식 창고 변경 기록

이 파일은 배포를 포함한 사용자 관점의 변경을 날짜별로 기록한다. 과거 Git 커밋 전체의 날짜·제목·해시는 [COMMIT_HISTORY.md](COMMIT_HISTORY.md)에 보관한다. 코드의 정확한 변경 내용은 해당 해시의 Git diff가 기준이다.

앞으로 기능, 콘텐츠, 화면, 운영 설정을 바꿀 때 같은 커밋에서 이 파일에 **무엇을 바꿨는지, 근거와 출처, 검증 결과, 배포 상태**를 추가한다. 개발 환경이나 배포 경로가 바뀌면 [DEVELOPMENT_ENVIRONMENT.md](DEVELOPMENT_ENVIRONMENT.md)도 함께 갱신한다. 비밀 값과 개인정보는 문서에 적지 않는다.

## 2026-10-02 · 도면 안 관찰 박스와 층별 요약

- 생활실의 ‘현재 N명’ 문구를 사람 아이콘과 숫자로 줄였다. 이름·현원은 툴팁과 접근성 이름으로 보완하고 실제 0명과 현원 미연결을 구분한다.
- 경고 클릭 정보를 별도 오른쪽 목록에서 3D 화면 안 오른쪽 위 박스로 옮겼다. 생활실명·현원·정원·집중·주의 숫자를 보여주고 클릭 때 화면 스크롤이나 카메라·보기 전환을 하지 않는다. 닫기·현황 다시 열기·Esc를 지원한다. 층 선택 목록의 집중·주의 숫자를 제거했다.
- 건물 전체·층별 펼치기에서는 공간별 표식을 층당 하나의 요약으로 바꿨고 선택 층·평면은 생활실별 표시를 유지한다. 층별 현원·관찰 숫자는 ERP의 명시적인 층으로 집계하며 도면 미연결도 해당 층에서 확인한다. 모바일 전체 보기에서는 스크롤 가능한 화면 안 박스로 요약한다.
