# 더비다 지식 창고 변경 기록

이 파일은 배포를 포함한 사용자 관점의 변경을 날짜별로 기록한다. 과거 Git 커밋 전체의 날짜·제목·해시는 [COMMIT_HISTORY.md](COMMIT_HISTORY.md)에 보관한다. 코드의 정확한 변경 내용은 해당 해시의 Git diff가 기준이다.

앞으로 기능, 콘텐츠, 화면, 운영 설정을 바꿀 때 같은 커밋에서 이 파일에 **무엇을 바꿨는지, 근거와 출처, 검증 결과, 배포 상태**를 추가한다. 개발 환경이나 배포 경로가 바뀌면 [DEVELOPMENT_ENVIRONMENT.md](DEVELOPMENT_ENVIRONMENT.md)도 함께 갱신한다. 비밀 값과 개인정보는 문서에 적지 않는다.

## 2026-10-01 · 도면 자동 구성·공간 이름 연결·건물 삭제

- 이미지·PDF 도면에서 닫힌 사각형 공간 후보를 만들고, 한국어 이름을 위치에 연결해 생활실·사무실·식당·복도 등의 용도를 채운다. 사용자 확인·수정 후 적용하며 PDF는 해당 층의 페이지를 먼저 선택한다. 기존 공간 교체는 별도 선택이다. 합성 도면으로 체험하는 예시를 제공한다.
- 건물 삭제 확인과 새로고침 전 삭제 되돌리기를 추가했다. 원래 저장본과 미저장 편집 상태를 구분해 복구한다.
- 근거: 이미지·PDF 자동 구성, 도면의 공간 이름 자동 매핑, 건물 삭제에 대한 사용자 요청. [PDF.js](https://mozilla.github.io/pdf.js/examples/)와 [Tesseract.js](https://github.com/naptha/tesseract.js/blob/master/docs/api.md)의 공식 배포를 라이선스와 함께 자체 파일로 제공한다. 도면 분석과 글자 인식은 브라우저에서 처리한다.
- 검증: 공간 경계·문 틈·배경·가구 중복·이름 위치·오탈자 제안·JSON 보존과 기존 탐색·대시보드 검사를 포함한 Node 테스트 27건, UI·정적 배포·기능 안내·공개 바이너리 경계 Python 테스트 12건 통과. 로컬 브라우저에서 예시 이미지 OCR과 PDF 2페이지 선택으로 각각 공간·이름 7개 연결, 3D 적용·저장, 삭제 취소·삭제·되돌리기·새로고침 복구, 기존 공간 겹침 차단과 명시적 교체, 320px 가로 넘침 없는 후보 편집을 확인했다. 사용자 파일 선택은 Chrome 확장의 파일 접근 권한 제한으로 자동 검증하지 못했으며 예시는 동일한 등록·분석 경로로 처리한다.
- 배포: 커밋 `fbf2104`를 `petdev`에 반영했다. [시설 3D 도면](https://app.aivida.tech/facility-3d.html)에서 PDF 2페이지의 공간·이름 7개 연결, 3D 적용·저장, 예시 건물 삭제·되돌리기를 확인했다. 기존 저장 건물은 유지했다. PDF·글자 인식 자료와 WASM 등 필수 정적 파일은 운영 주소에서 HTTP 200으로 제공된다.

## 2026-09-30 · 시설 3D 도면 추가

- ‘시설 인수·개설’에 ‘시설 3D 도면’ 카드를 추가했다. 5층 요양원 예시를 회전·확대하고 건물 전체, 층별 펼치기, 선택 층, 평면 편집으로 살펴볼 수 있다.
- 1~12층 새 건물, 선택 층의 도면 이미지 등록, 사각형 공간 추가와 용도·침대 수 편집을 제공한다. 치수를 생략하면 추정 크기로 시작한다. 건물 저장은 현재 브라우저에 보관하며 JSON 파일로 내보내고 다시 열 수 있다.
- 근거: 다층 건물을 3D로 볼 수 있는 새 카드를 만들라는 사용자 요청. [공식 npm Three.js 0.186.1](https://registry.npmjs.org/three/-/three-0.186.1.tgz)을 MIT 라이선스와 함께 자체 정적 파일로 제공한다. 기존 Python 서버와 Railway 배포 구조를 사용한다.
- 검증: 도면 경계·겹침·JSON 검증, 탐색·대시보드 Node 테스트 20건과 UI·정적 배포·지식 안내 Python 테스트 13건 통과. 로컬 브라우저에서 5층 3D, 층 선택, 공간 편집, 치수 없는 새 건물, 공간 추가, 저장·새로고침, 키보드 조작, 320px 가로 넘침, 실제 JSON 내보내기와 파일 검증을 확인했다. 이미지·JSON 파일 선택의 브라우저 자동 검증은 Chrome 확장의 파일 접근 권한 제한으로 확인하지 못했다.
- 배포: 커밋 `1ba9fe6`을 `petdev`에 반영했다. [시설 인수·개설](https://app.aivida.tech/?category=facility)에서 카드 2개와 새 페이지 연결, [시설 3D 도면](https://app.aivida.tech/facility-3d.html)에서 5층 예시의 건물 전체·층별 펼치기 렌더링을 확인했다. 새 정적 페이지와 JavaScript는 운영 주소에서 HTTP 200으로 제공된다.

## 2026-09-28 · 통계자료 기사 인용 수치 추가

- 보건복지부가 국회에 제출한 자료를 인용한 [검경일보 기사](https://www.ppnews.kr/news/articleView.html?idxno=89120)의 신체 구속·감금 학대 판정 피해노인 수(2023년 72명, 2024년 161명, 2025년 184명)와 2025년 5월 신체억제대 사용 시설 수(3,940곳)를 통계자료 책갈피에 추가했다.
- 보도 기사 인용임을 화면에 표시하고 공식 PDF 원문 캡처와 다른 형식으로 보여준다. 사용 시설 수를 학대 판정 시설 수 또는 사고율로 해석하지 않도록 주의 문구를 넣었다. 공개 원자료는 직접 검증하지 못했다.
- 기사 메타데이터와 수치의 계보를 `data/statistics_article_sources.json`에 저장하고 검색·책갈피·지식 창고 데이터 내보내기에 연결했다.
- 검증: `node test_statistics.cjs`, `node scripts/build_service_catalogs.cjs --check`, `python -m unittest test_ui_consistency.py test_static_pages.py` 통과. 로컬 브라우저에서 검색·상세 보기·좁은 화면을 확인했다. `test_card_knowledge.py`의 홈페이지 카드 등록 검사 1건은 수정 전 `petdev`에서도 같은 3개 페이지 등록 누락으로 실패한다.
- 배포: 커밋 `de17e88`을 `petdev`에 반영했다. Railway `competitors`/`dev`에서 배포 성공 및 활성 상태를 확인했고, [운영 통계자료](https://app.aivida.tech/statistics.html)에서 기사 인용 카드 2개, 9개 출처·29개 책갈피, `억제대` 검색 결과를 확인했다.
