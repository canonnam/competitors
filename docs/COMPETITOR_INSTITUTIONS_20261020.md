# 경쟁사 대상 기관 분류

2026-10-20 사용자 요청으로 서비스 탐색에 대상 기관 필터를 추가했다.

## 분류 기준

- 공개된 지원·운영·제휴 대상을 복수 분류한다. 실제 유료 고객이나 동일 기능의 모든 기관 제공을 뜻하지 않는다.
- 요양시설에는 요양원·노인요양공동생활가정을 포함하고 요양병원·시니어주거와 구분한다. 방문목욕·간호는 하나의 탐색 묶음이며 세부 범위는 상세에서 밝힌다.
- 주간보호는 주야간보호에 포함한다. 가정용 로봇이라는 이유만으로 방문요양기관 지원으로 분류하지 않는다. 시립 요양원은 지자체 일반 업무가 아닌 요양시설 사례로 분류한다.
- 기관 분류 확인일은 별도 메타데이터다. 일괄 분류만으로 기존 제품·동향 업데이트 날짜를 모두 최신으로 바꾸지 않는다.
- 29개 기록의 분류·설명·출처 원본은 `assets/competitors-data.js`의 `institutionResearch`다. 카드·상세·비교표·검색과 생성된 지식 카탈로그가 같은 데이터를 사용한다.

## 확인 제한

- 올케어ERP와 지팡이는 공개 소개에서 장기요양기관 세부 유형별 지원 범위를 확정하지 못해 ‘확인 필요’로 두었다.
- 코리아케어플랫폼 AI 요양 서비스는 원장·임직원·보호자 역할을 명시하지만 세부 기관 유형은 불명확하다. 연결된 요양AI&GPTs의 요양원 예시를 별도 서비스에 자동 적용하지 않았다.
- 행복커넥트는 기존 조사에서 지자체 돌봄 사업을 확인했으나 10/20 공식 주소 재접속이 404로 실패했다. 기존 분류 근거와 현재 공급 범위 확인 필요를 명시했다.
