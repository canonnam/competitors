# 2026-11-18 평판 점검 복구 이력

## 요청과 기존 상태

OpenAI API 키 없이 기존 Railway에서 정기 평판 점검을 실행하도록 수정했다. 기준 자료는 운영분석 `automation-monitor/2026-11-18.md`와 `evidence/reputation-retained-cache-20261118.json`이다. 운영 원본을 별도로 읽어 현재 수집 4/6, 최신 27건 중 22건 미분류, 분류 HTTP 401과 당일 8회 소진을 확인했다.

## 적용 내용

평판 분류만 서버 내부의 규칙 기반 선별로 전환했다. 판정 기준과 버전·중복 처리 절차는 [평판 선별 기준](REPUTATION_RULES.md)에 정리했다. 안내·채용 등 부정 표현 미감지와 원문 확인 대기를 표시하고, 후보별 근거 구절·판정 이유를 보관한다. 홈페이지와 상세 화면의 오류·미완료 표시는 기존 수집 상태를 따른다.

## 운영 저장본 재현

API 키가 없는 환경에서 최신 문서 27건을 처리해 부정 표현 미감지 25건과 원문 확인 대기 2건을 얻었다. 이전 버전의 이미 분류된 5건도 새 규칙으로 재검토했으며, 이전 분류 행을 보존했다. 확인 대기 2건은 채용 관련 문구의 문맥 부족과 AI 생성 안내가 섞인 검색 요약이다. 과거 수집 실패 출처의 캐시는 당일 분류 대상에서 제외했다.

원본 수집처 상태·과거 분류·이력을 전후 대조하고 재실행에서 새 분류가 중복 저장되지 않음을 확인했다. 네이버 `naver-2`, `naver-4`의 결과 검증 실패와 이전 캐시는 보존했으며 출처 재시도 한도를 초기화하지 않았다.
